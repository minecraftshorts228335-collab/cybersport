# Киберспортивный Турнир — Итоговый проект по Python и CS

## Назначение проекта
Консольное и веб-приложение для управления базой данных киберспортивного турнира. Программа позволяет автоматизировать учёт игроков и команд, производить быстрый поиск, сортировку по рейтингу, управлять очередью матчей и сохранять актуальное состояние системы.

## Требования и зависимости
- Язык программирования: **Python 3.10+**
- Используются **исключительно стандартные библиотеки Python** (без внешних фреймворков и сторонних пакетов).

## Структура модулей проекта
1. `models.py` — доменная логика: абстрактный базовый класс, структуры `dataclass` (`Player`, `Team`, `Match`), собственные алгоритмы поиска (линейный O(N)) и сортировки (Bubble Sort O(N²)), а также генератор топа участников и очередь матчей (`deque`).
2. `server.py` — серверная часть на базе встроенного `http.server`, обработка HTTP-запросов (GET/POST), маршрутизация, работа с хранилищем CSV/JSON и логирование.
